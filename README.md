This is a simple project that compare several sorting algorithms:
1. bubble sort
2. insertion sort
3. merge sort
4. quick sort
5. selection sort

All headers are included in **master.h** such that only the aformetioned is included in **main.c**

In the folder *src* you will find the headers and implementation for 
1. **data generation**
2. **helpers** - atm: functions for **get_time** and **check_sorted**

In the folder **LINUX-bash-scripts-COMPILE** you will find the bash scripts I use on Ubuntu (and Linux in general) to compile my code
(see: https://github.com/VladArambasa/geany-config and https://github.com/VladArambasa/arch-mkproj-c-cpp)
